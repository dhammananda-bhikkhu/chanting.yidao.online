# 忏罪

## 下座向上座忏罪
下座：Ahaṃ，bhante，sabbā āpattiyo āvikaromi / ārocemi.<br>
上座：sādhu，āvuso，sādhu sādhu.<br>
下座：Ahaṃ，bhante，sambahulā nānāvatthukā sabbā āpattiyo āpajjiṃ,
tā tumhamūle paṭidesemi.<br>
上座：Passasi，āvuso, tā āpattiyo？<br>
下座：Āma，bhante，passami.<br>
上座：Āyatiṃ，āvuso，saṃvareyyāsi.<br>
下座：sādhu，suṭṭhu，bhante，saṃvarissāmi.<br>
上座：Sādhu，āvuso，sādhu sādhu.<br>

## 上座向下座忏罪
上座：Ahaṃ，āvuso，sabbā āpattiyo āvikaromi / ārocemi.<br>
下座：sādhu，bhante，sādhu sādhu.<br>
上座：Ahaṃ，āvuso，sambahulā nānāvatthukā sabbā āpattiyo āpajjiṃ，
tā tuyhaṃ“图一行” mūle paṭidesemi.<br>
下座：Passatha，bhante，tā āpattiyo？<br>
上座：Āma，āvuso，passami.<br>
下座：Āyatiṃ，bhante，saṃvareyyatha.<br>
上座：Sādhu，suṭṭhu，āvuso，saṃvarissāmi.<br>
下座：Sādhu，bhante，Sādhu Sādhu.<br>

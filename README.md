# 课诵站 · 内容库

这里是 chanting.yidao.online 的文稿。

网站是为「手机上边念边看」做的：巴利与中文一句一对应，
字号可调，可以只看巴利、只看中文，或两者对照。

## 想提意见

网站每一页右上角有个 **G**，点一下就到这里对应的那个文件。

- **错字、拼写、译文的问题**——在那个文件页面点右上角的铅笔，
  或者开一条 [Issue](../../issues/new)，说清楚是哪一行、应该是什么。
- **排版、分类、功能的建议**——同样开一条 Issue。

看得懂 GitHub 的，也可以直接提 Pull Request。
